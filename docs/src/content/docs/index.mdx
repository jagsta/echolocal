## What EchoLocal is

EchoLocal replaces Amazon's services on the Echo with a single program that drives its speaker,
microphones, buttons, light ring, screen and camera directly, and talks only to your Home Assistant.
It speaks the ESPHome native API, so Home Assistant finds it like any ESPHome device.

## The EchoLocal integration

Optional, from HACS: a card for every Echo, a dashboard with all of them, Fleet to compare and copy
settings between them, turn history with recordings, a wake word library, custom tones, groups and
health. It works with [LANovo](https://www.lanovo.link) displays too.
