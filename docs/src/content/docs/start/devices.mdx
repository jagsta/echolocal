## Echo Dot (2nd gen, biscuit)

No screen: a twelve-segment light ring, four buttons and a seven-microphone array. Everything is set
in Home Assistant or on the [EchoLocal card](/start/integration/). See
[Echo Dot: buttons and light ring](/use/dot/).

## Echo Show 5 (1st and 2nd gen, checkers and cronos)

The first and second generation Show 5 look the same and run the same software. The second
generation comes with two different speaker amplifiers; EchoLocal handles both.

## Echo Show 8 (1st gen, crown)

A bigger screen, a larger dashboard grid, and stereo speakers.

## Echo Show 8 (2nd gen, athena)

The same screen and stereo speakers as the first generation. Its camera goes up to 1920 × 1080 and
is the only Echo camera with a [sub stream](/features/camera/#rtsp).

<Aside type="note">
Other Echos aren't supported yet.
